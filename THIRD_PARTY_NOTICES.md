# Third-party components

- **Spark-X2.6 model weights and model code:** Apache License 2.0 as stated by XHToken. Obtain model weights from the official project/model collection and review each conversion's own license.
- **llama.kt / llama.cpp inference engine:** `tensai-app/llama.kt` is Apache-2.0; its upstream and bundled components include separate licenses listed in its own `THIRD_PARTY_LICENSES.md`.
- **ML Kit image labeling:** Google's ML Kit Android SDK, distributed under its published Google terms.
- **Tesseract4Android:** open-source Tesseract Android wrapper; see <https://github.com/adaptech-cz/Tesseract4Android> and its license file.
- **Tesseract English/Persian traineddata:** `tesseract-ocr/tessdata_fast` repository; review the repository's data license.
- **AndroidX / Jetpack Compose / Kotlin / coroutines / Android platform APIs:** their respective upstream licenses and notices apply.

No model weights are bundled into the repository. Users download and import GGUF files themselves.
